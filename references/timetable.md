# 可选课表匹配规则

本文件只有通用规则，不含个人排课数据。首次配置可复制 [空白课表模板](timetable.template.md) 为本机的 `timetable.local.md`。

1. 使用用户当前提供的课表，或仅保存在本机的 `timetable.local.md` / `timetable.local.json`；确认适用学期。
2. 按课程全名或课程代码唯一匹配，结合报告或手册确认归属；不得只凭相似实训题目猜课程。
3. 报告与手册已有明确教师信息优先；普通实训可在课程唯一匹配且不存在专门实验教师冲突时，用任课教师补空白普通文字栏。已有签名图片的区域保留图片，不追加姓名。
4. 若用户提供某周某日的已确认日期，可先求该周周一，再减去 `7 × (周次 - 1)` 天得到第 1 周周一。目标日期为该基准加 `7 × (目标周次 - 1) + (星期序号 - 1)` 天，周一序号为 1。调课、停课或非连续教学周按用户说明处理。
5. 没有周次基准或无法唯一匹配时不推断实验日期；日期兜底按 report-rules 执行，不把普通报告日期说成已核实实验日期。
6. 只使用当前报告必需的信息，不联网搜集教师或学生个人资料，不为补齐无关字段扩大调查。

真实课表、截图、PDF 和周次基准应留在本机；如需保存附件，放在被 Git 忽略的 `private/` 目录。
