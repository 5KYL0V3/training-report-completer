# 实训报告填写规则

通用任务读“材料与位置”“身份”“字号与模板协调”“各栏填写”“文件与命名”“验收”。涉及真实研究或截图时再读“真实检索与截图”。

## 材料与位置

- 当前提交 DOCX 的要求优先于手册；二者冲突按 DOCX。老师已给的目的、原理、任务、要求、仪器与用具、操作步骤优先原样复制。不要替换已有正确内容，也不要把补写文字标成老师原文。
- 先理解整份文档，在内部清单记录正文段落、表格 / 嵌套表格、空白单元格、明显留白、步骤 / 过程、结论心得、教师评语、评分、学生、指导教师及身份栏。检查页眉页脚、文本框、内容控件里的实际要求。
- 识别黄色高亮、彩色提示、底纹、“（写）”“（截图）”“截图与写”等。没有标记的明显学生填写区域也要完成。空段落、装饰色和表格排版留白本身不等于待填写要求，应结合相邻标签判断。
- 若高层 API 漏项，检查相关 DOCX XML（w:highlight、w:shd、w:color、w:tbl、w:sdt、w:txbxContent、DrawingML / VML 图片及关系）。图片数量不等于已满足的截图数量；保留已有图片 / 签名关系。避免整体设置 cell.text 或 paragraph.text 导致原图、样式和混合格式丢失。
- 清单区分必需成果、真实证据、可省略扩展；每项完成状态为“原要求完成”“提供替代成果”或“仍未完成”，另记有意留空或阻塞原因。只删除已完成位置的学生操作提示和确认属于提示的格式，保留题目、模板底纹及真实内容。尚未完成的截图提示不能删除后装作完成。

## 身份

正常运行读取同目录 `student-profile.md`，不从 template 文件取默认值。六个 YAML 字段都用字符串保存。

| 报告要求 | profile 字段 |
| --- | --- |
| 姓名、普通文字“学生”栏 | name |
| 学号 | student_id |
| 学号最后2位、学号（最后2位） | student_id 去首尾空白后取最后两个字符 |
| 班级、专业班级 | class |
| 专业 | major |
| 学院 | college |
| 学校 | school |

- 学号不转整数，保留前导零；不足两个字符时不猜最后两位。只处理确实属于身份标签的文字，不能全局替换正文中的“姓名”“班级”。替换组合标签时先处理“专业班级”“学号（最后2位）”，避免拆成错误字段。
- 缺文件或必需字段为空，列明缺什么及需要填写的位置，继续无关正文；依赖未知身份的正式文件名不能擅自用虚构值或匿名值完成。报告不要求的字段不应写入正文，也不必为它们阻塞。
- 模板已有身份与 profile 冲突时指出冲突，暂停有争议字段，不把另一人的资料默认为用户资料。
- 测试允许在隔离的技能副本建立明确标为 TEST ONLY 的虚构 profile；结束删除该文件，绝不安装 / 覆盖为正式 student-profile.md。

## 字号与模板协调

- 小四指 **12 磅（12 pt）**。无特殊要求且不会造成遮挡、溢出或明显分页异常时，新增正文、步骤、心得及表格内普通填写文字优先用小四。用户、老师或模板明确规定其他字号时从其要求；空白占位继承了其他字号，本身不等于老师有明确要求。
- 只设置本次新增或明确要求调整的文字，不改全文默认样式，不批量统一已有正文、表头、标题、编号、图注、页眉页脚及签名区域。新增图注优先沿用模板图注样式，无样式时与相邻说明文字协调。字体名称、粗体、颜色、对齐和段落间距继续沿用对应模板，不因“小四”顺带改为宋体或其他字体。
- 普通新增文字的中文、英文和数字使用协调一致的字号，保留公式、上下标等特殊格式。截图内文字不修改，不拉伸图片来追求截图文字与正文等大。
- 小四容纳不下时，先确认原因：内容冗余则精简重复表述，保留必要结果、书目信息及证据；固定行高、窄单元格等限制下，局部沿用模板字号或作最小字号调整，以清晰可读为限。不得持续缩字硬塞内容，也不为统一小四重做表格、全局改行高或跨页设置。模板本身确有遮挡问题时，仍按局部最小修复规则处理。
- 字号检查并入一次基础视觉验收，仅看本次填写区域是否清晰、协调、无明显遮挡。因明确要求或实际空间限制采用其他字号不算缺项，不增加检查轮次或为统一字号返工。

## 心得与评语的首行缩进

仅“实训结论与心得”及“教师评语”的正文自然段设置首行缩进 2 字符（OOXML `w:firstLineChars=200`）。不要扩展到全文、其他表格或左侧竖排栏名；评分、姓名、签名、标题、编号列表、图注及图片段落不套此格式。不插入空格或 Tab 模拟缩进，不改表格边距、宽度和合并关系。保留字号、行距、对齐与左右缩进，仅清除与首行缩进冲突的原 firstLine/hanging 设置。多段文字用真实段落，每段首行缩进，自动换行后的续行不缩进；原有文字无需改写，已有真实评语只调整明确要求的段落格式。若已有内容仅用软换行分段，先按实际语义确认分段，不把每条视觉换行都拆成段落。

## 各栏填写

**日期 / 时间**：报告日期栏优先使用用户、当前 DOCX 或实训手册明确指定的对应实训日期；明确来源冲突时按用户明确指令 > 当前 DOCX > 手册处理。均未指定时，先按 [课表匹配规则](timetable.md) 检查是否有课程、目标周次和用户确认的周次日期基准可唯一确定实训日期；条件不足时仍使用 Skill 实际执行当天的用户本地日期作为普通报告日期，不声称它就是实际实验发生日期：执行时按用户本地时区取得日期，不使用文件创建日期、技能示例日期或未经本地转换的 UTC 日期。优先沿用模板的日期格式，无法判断时默认 `YYYY.MM.DD`（例如执行当天为 2030-01-02 时填 `2030.01.02`）；模板明确给出 `2030.01.01` 时保留或填写该日期，不覆盖为当天。未要求具体起止时刻时不追问；若当前任务明确要求具体时刻，则仅使用已提供的可靠资料，缺少时列出对应待补项。老师正文、文献出版日期、截图中的真实日期属于材料内容，原样保留，不作为报告实训日期的默认值。

**步骤 / 过程**：已有流程按材料组织为普通本科实训报告的学生操作叙述；要求原文的栏目仍照录。缺失时根据目的、任务、原理、手册合理补写，简明连贯、不离题，不进行学术级研究。不能编造测量值、运行日志、已验证的硬件状态或真实检索成功。无实际操作证据时可写操作流程和预期观察，不把它描述成已实测结果；确需真实结果则列为待补。

**结论与心得**：为空则自动补充完成内容、掌握的方法、典型问题与收获，可有简单反思。围绕当前实训，不堆术语；没有材料支撑时把问题写成应注意事项，避免假称本人遇过。无需联网，优先与步骤一起委派。

**教师评语**：仅在当前任务已授权补充该栏目时填写，已有授权不重复确认；否则保留该栏目。授权范围内空白时填写约 50 字的正式评语，围绕当前报告的内容完整度、方法或过程作具体判断，与实际完成程度一致；已有真实教师评语保留。

**评分**：仅在当前任务已授权填写评分时处理。授权范围内空白时默认“优”；明显缺项、真实检索未完成或只能部分完成时填“良”。除非用户另外明确要求，不生成及格、中、不及格或数字分数。直接写“优”或“良”，不写“良（建议）”；已有真实评分不擅自改动。

**自动填写的文字边界**：正文、教师栏目、批注、脚注及交付说明均不添加“建议”“建议评语”“建议评分”“供教师参考”“供教师审核”“待教师确认”“自动生成”“AI拟写”等提示标签，也不换用类似免责声明。此规则针对自动添加的标签和免责声明，不机械删除原文中具有正常语义的“建议”，不擅改已有真实教师批阅；不伪造手写签名，不声称教师实际签署或批阅过。未完成的检索、导出、下载仍须如实说明。

**学生**：普通文字填 name。手写签名 / 签名图片区域不伪造、不插入生成签名，保留已有图片。

**指导教师**：先检查底部最终填写区域，**已有签名图片的优先级最高**。检查该区域的完整单元格、相关段落与文本框，以及归属于该区域的图片、Drawing、InlineShape 和对应 OOXML 对象（如 `w:drawing`、`wp:inline`、`wp:anchor`、`w:pict` / VML 及图片关系）；不能只看段落或单元格提取文本，文本为空不代表没有签名。不要因文档其他位置有图片就误判本栏已有签名。

- 区域已有签名图片：保留原图片、锚点和关系，不再自动填写教师姓名文字。不得整体重置单元格或段落而删除图片。
- 若本轮已在含签名图片的同一填写区域额外插入与顶部指导教师相同的姓名文字，依据本轮写入记录或与原件的差异，只删除自动插入的重复文本节点；保留签名图片、标签和原有文字。不能仅因原件已有同名文字就擅自删除。
- 只有底部区域没有签名图片时，才读取报告顶部已有“指导教师 XXX”的明确姓名，填写到底部空白普通文字栏。顶部也无姓名时，可按 [课表匹配规则](timetable.md) 使用对应学期、唯一课程的任课教师补空白普通实训教师栏；无法唯一匹配或存在专门实验教师等区分时保持为空，不猜测、不联网搜人。多个冲突姓名时只暂停相关字段并说明。

## 文件与命名

1. 记录输入绝对路径，在副本上编辑。inspect 的 source_sha256 供 apply 防止使用过期位置；不要另做无意义的重复哈希。保存前核对输出不指向原件，最终默认输出到输入 DOCX 的父目录，用户指定交付目录时从其要求。中间稿、旧版本、渲染与 patch 放本次 work 目录；正式位置只放明确最终报告及用户需要的附件，不擅自删除用户文件。
2. 文件名有身份占位符，按 profile 替换“学号（最后2位）”、等义写法、“学号”“姓名”“专业班级”“班级”等明确占位符。保留主体与字段顺序；`+` 一律视为字段分隔提示并删除，最终文件名不得有加号，此规则同时适用于已有具体身份的文件名与显式输出名。
   - 仅作 TEST ONLY 示例：学号 `000007`，姓名 `测试同学`，班级 `测试班`。
   - `学号（最后2位）+姓名+班级+实训2文献信息检索2.docx` → `07测试同学测试班实训2文献信息检索2.docx`。
   - `07+测试同学+测试班+实训3外文文献线索检索与利用实训.docx` → `07测试同学测试班实训3外文文献线索检索与利用实训.docx`（仅示范文件名转换，不作为身份默认值）。
3. 无身份占位符时，只清除扩展名前连续的下载副本后缀，例如 `(1)`、`(2)`、`(1)(1)`（可含邻接空格 / 全角括号）。有证据为课次、版本、任务编号的数字括号不删，不改正文标题或主体名。
   - `6.实训报告（keil5环境搭建与点灯）(1)(1).docx` → `6.实训报告（keil5环境搭建与点灯）.docx`。
4. 如果按规则得到的目标路径就是原始输入（包括大小写、符号链接或硬链接指向同一文件），原件保护优先。有明确身份命名要求而碰撞时暂停正式命名并说明；没有明确命名要求时，保留主体，仅加 `_已填写` 以避免同名覆盖。仅此冲突情形使用区分后缀，不默认命名为 `完成版.docx`、`final.docx` 或 `实训报告_完成版.docx`。
5. 已有目标仅当确定是先前生成的完成版时可以覆盖（本次会话记录或可核验的生成记录），不能仅凭同名认定。目标是另一份原件或来源不明时保留，采用可区分的目标；若违反明确命名要求则暂停该命名决定。用户资料含 Windows 文件名非法字符时说明相关字段，不静默改变身份。
6. apply 已在临时文件保存、做一次打开验证并原子写目标，不再重复同类检查。正式目录不可写时反馈具体权限阻塞，工作副本可暂存，但不能宣称仅临时路径已满足交付要求。遵守实际工具权限机制，并说明任何未能满足的路径要求。

## 真实检索与截图

仅在用户或文档明确要求时进入此节。C 级真实来源研究不自动要求截图；D 级每项截图要求都要真实取证。网站 / 数据库、检索词、筛选条件与截图目标以当前文档要求为准。

- 优先使用用户指定且已经登录的浏览器会话，在同一会话连续完成检索、截图、导出和下载。必须切换工具或会话时先确认登录是否继承；新会话未登录不等于用户没有登录。只有当前必需操作明确被登录或验证码挡住时，才一次说明受影响操作并请用户处理。
- 开始时先验证必需的原生导出、指定文献全文获取等容易阻塞的路径，只判断可用，不扩展为额外研究。页面点击后用目标图表、结果区域或加载状态进行有界就绪检查：一次短等待，未就绪时最多再查一次，总计不超过 30 秒；仍未就绪记录阻塞。不以即时截图为空判定失败，不固定长等或循环刷新。实际页面错误按 local-environment 的失败分类和重试上限处理。
- 手工书目表不等于平台原生导出，补充文献不等于指定文献下载，打开教程页不等于完整阅读。逐项记录原要求完成、提供替代成果或仍未完成；交付措辞与证据一致，未经核实不宣称全部完成。

- 内部截图清单逐项记录：编号、DOCX 位置、指定站点 / 数据库、检索式或操作、所需页面内容、真实 URL、获取时间（只作内部追溯）、图片路径、状态、插入位置。内部记录时间不填入报告日期栏。
- 每一个“（截图）”或“截图与写”单独对应。即使内容相似也不能合并省略；除非同一真实图片确实满足两个独立要求且已逐项核验，否则不能重复用图充数。已有用户截图满足要求可复用，不得声称是刚执行的新操作。
- 截图来自实际访问的真实网页 / 数据库与真实检索操作。若模板明确要求软件操作界面，则来自该真实软件操作；软件图不能代替要求的网页检索证据。AI 生图、自画网页、文字转图片、截图编辑合成均不可冒充真实取证。
- 保留网站名、页面标题、关键词 / 检索式、真实结果与关键区域。允许裁掉广告和大块无关区域，但不能裁到来源不可辨或改变结果含义；插入 Word 后字仍应可读，按可用宽度等比缩放，必要时分图或合理换页。来源与图片应对应，不能用文字说明代替缺失图片。
- 网页打不开、需要无法完成的登录、访问受限、验证码、数据库无结果、或无法取得要求截图时，立即说明“要求编号、站点、已做操作、具体阻塞、受影响位置”，暂停依赖该项的研究 / 结论 / 图片。不得擅换数据库或来源、绕过访问限制、循环重试或伪造成功；继续其他不受影响的部分，等待用户决定来源替代、提供材料或稍后再试。
- 不足以得到要求结果的零命中视为阻塞；如果题目本来要求展示零命中页面，该真实页面可满足该项，但不得虚构非零结果。只有明确获准替换来源后才执行替代方案。
- 部分完成可以交付诚实标明状态的工作成果并用“良”，但“良”不能使截图缺失项变成已完成，不称其为已经通过全部提交要求。

## 验收

- 逐项核对需求清单和截图证据，不用图片总数代替对应关系。主 agent 对委派结果做必要抽查，不重复全部研究。
- 必填正文、步骤、心得、普通文字学生栏及授权范围内的教师评语、评分完整；指导教师按签名图片优先规则处理。检查该区域是否同时出现“签名图片 + 本轮自动填写的同名教师文字”，若存在即 QA 失败，自动删除本轮重复文字后重新检查，确认原签名图片及其关系完整保留；无签名图片时按报告顶部优先、课表唯一匹配补缺的规则填写姓名。
- 日期使用明确指定日期、课表与用户确认的周次日期基准唯一匹配出的日期或作为普通报告日期的执行当天本地日期，格式沿用模板或默认 YYYY.MM.DD；不得擅填时分秒。有意留空的独立时分秒栏、手写签名或未知教师姓名不算遗漏。
- 学生资料、学号末两位、文件名及前后事实一致；没有把未要求的身份信息写入报告，没有残留已完成任务的提示，没有误删正文。
